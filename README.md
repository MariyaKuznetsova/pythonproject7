# Приложение для поиска вакансий

## Описание:

Приложение для поиска вакансий - Приложение получает информацию о вакансиях с платформы hh.ru в России, сохраняет ее в файл и позволяет удобно работать с ней: добавлять, фильтровать, удалять.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/pythonproject8.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Приложение запускается из основного модуля main, в котором собраны все функциональности приложения.
